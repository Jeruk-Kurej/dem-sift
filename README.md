# DEM-SIFT

An educational Unity game that teaches children about dental health.

## What is in it

- **Six lessons:** tooth structure, cavities, how cavities form, brushing frequency, sorting foods, and visiting the dentist.
- **Three practice activities:** choosing a toothbrush, choosing toothpaste, and the steps of brushing.
- **Drag-and-drop puzzles and quizzes** with shuffled answer trays.
- **Scoring:** points per question, a penalty for wrong answers, and a result popup.
- **Player entry and leaderboard:** players enter a name and class, and results are saved to a text file.
- **Admin panel** behind a PIN for managing saved results.

## Stack

Unity 6 (6000.6.0f1), C#.

## Running it

1. Open the `unity` folder as a project in Unity Hub with Unity 6000.6.0f1.
2. Open `Assets/Scenes/MainMenu.unity`.
3. Press Play.
